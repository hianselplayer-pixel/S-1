# Serpent Vanguard: Rogue Defense (靈蛇先鋒：賽博幾何防衛戰)

**Serpent Vanguard** 是一款結合經典貪吃蛇機制與高張力賽博朋克 Rogue-lite 彈幕防守的網頁遊戲。玩家將操作配備重裝火力與護盾的機械靈蛇，守衛普羅米修斯反應爐核心，抵禦排山倒海而來的賽博幾何敵人群體！

---

## 🌟 核心特色與玩法 (Core Features)

1. **獨特靈蛇戰術操作**：
   - **蛇頭主戰武裝**：掛載機關槍、雷射、電漿迫擊砲、特斯拉電弧等重火力主砲。
   - **蛇身身軀支援**：隨等級提升自動延長蛇身，串聯多種防衛砲塔與支援模組（冰凍射線、火焰噴射、佈雷器、防護盾發電機等）。
   - **共振環爆**：當蛇身足夠長並自行繞成閉環時，可觸發超導幾何共振環爆，對周遭敵軍造成毀滅性AOE傷害。

2. **同心環陣列進攻與統一律動**：
   - **同心環陣列出場**：所有幾何敵人在每波進攻時皆會於外圍同心環集結，以陣列同步推進。
   - **律動行停節奏**：全體怪物採用統一的「前進 1.5 秒、停止 0.8 秒」循環律動（行停行停），帶來極具節奏感的戰術走位考驗。

3. **清晰流暢的視野與彈幕設計**：
   - **子彈縮小與半透明**：所有玩家與敵方彈道皆已大幅縮小並具備半透明效果，確保彈幕密集時視野依然清晰。
   - **精簡普通怪體型**：所有普通幾何怪物體型適度縮小，畫面乾淨俐落。

4. **基於擊殺比例的等級系統**：
   - 最大等級 20 級。
   - 升級進度改為依據「目前擊殺數 / 預期整場敵人總數」的精準比例判定（如 0.05% 升至 Lv.1、0.1% 升至 Lv.2、1% 升至 Lv.3 等，逐步提升難度）。

5. **量子輪盤召喚與裝備系統**：
   - **四大稀有度**：UR、SSR、SR、R 稀有度概率嚴格加總為 100%。
   - **多欄位與重複突破**：支援 6 個幾何護符裝備欄位，重複抽中護符可直接進行星級突破（Lv.1 ~ Lv.MAX）。
   - **機型切換**：解鎖並切換多款傳說級巨蛇機型（先鋒獵手、泰坦重盾、虛空超導、裂變巨神），同步變更戰場蛇身造型與機體數值。

6. **多層防護與史詩 Boss 戰**：
   - 包含 10 層護盾防護壁與專屬血條的巨型幾何首領（超維泰坦、虛空湮滅星核、萬象幾何原初巨神）。
   - 達成特定條件（無傷過關、全套高級護符、擊殺數）可解鎖成就與額外零件獎勵。

---

## 🚀 技術堆疊 (Tech Stack)
- **Framework**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide React
- **Rendering**: HTML5 Canvas 2D (1:1 高解析度渲染與相機縮放)
- **Audio**: Web Audio API (合成音效與背景音樂)

---

## 🛠️ 開發與執行 (Development)

在終端機中執行以下指令即可啟動開發伺服器：

```bash
# 安裝相依套件
npm install

# 啟動開發伺服器 (Port 3000)
npm run dev

# 專案建置
npm run build
```
